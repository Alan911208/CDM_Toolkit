============================================================
VERIFICATION CRITERIA
============================================================

PASS: Excel launches (or existing instance is used) and a new workbook
      is created.
PASS: The workbook contains one sheet per dataset (DM, AE) plus a TOC
      sheet.
PASS: TOC sheet correctly lists all datasets with location and change
      counts.
PASS: Changed cells display old/new values separated by "/".
PASS: Changed cells are highlighted YELLOW.
PASS: New records are highlighted GREEN.
PASS: Intermediate temporary sheets created during processing are
      deleted at the end.
PASS: No data is lost or corrupted.

============================================================
SYSTEM REQUIREMENTS
============================================================

  - Windows OS (DDE is a Windows-specific protocol)
  - Microsoft Excel installed and DDE enabled:
    File > Options > Advanced > General >
    "Ignore other applications that use Dynamic Data Exchange (DDE)"
    MUST be UNCHECKED.
  - Recommended: 32-bit SAS + 32-bit Office for reliable DDE
  - NOT suitable for server/headless/batch environments

============================================================
TROUBLESHOOTING
============================================================

  If Excel does not open:
    - Verify DDE is enabled in Excel options
    - Try launching Excel manually before running the macro
    - Consider using 32-bit SAS if using 64-bit

  If cells show "ERROR" or truncated data:
    - Reduce dataset size (DDE has buffer limits)
    - Increase the DDE channel lrecl in the macro code

  If sheets are not color-coded:
    - Ensure Excel's DDE channel is not blocked by antivirus
