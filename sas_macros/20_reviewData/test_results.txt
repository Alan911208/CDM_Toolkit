============================================================
VERIFICATION CRITERIA
============================================================

PASS: Excel launches (or existing instance is used) and a new
      workbook is created.
PASS: The workbook contains one sheet per eligible dataset plus a TOC.
PASS: Excluded datasets (WVISIT, LABREF, CMEDDRA, CUSERD, MISPAGE,
      CWHODD, PAGESTATUS, CROSSCHK, TRANSLATION, QUERY, FORMATS, PAT)
      do NOT appear as data sheets.
PASS: AUXILIARY datasets (QUERY, CROSSCHK) do NOT appear as data sheets
      but their findings ARE applied to the corresponding data sheets.
PASS: TOC sheet lists all datasets with descriptions.
PASS: Color coding matches the finding codes defined in the legend.
PASS: If showFail=YES and unmatched findings exist, a diagnostic
      dataset is created in WORK with a WARNING in the SAS log.
PASS: Temporary intermediate sheets are cleaned up.
PASS: No data is lost or corrupted.

============================================================
SYSTEM REQUIREMENTS
============================================================

  - Windows OS (DDE is a Windows-specific protocol)
  - Microsoft Excel installed and DDE enabled
  - Recommended: 32-bit SAS + 32-bit Office
  - NOT suitable for server/headless/batch environments
  - fmtsearch option uses dReview.formats if the FORMATS dataset
    exists in the library

============================================================
TROUBLESHOOTING
============================================================

  If Excel does not open:
    - Verify DDE is enabled in Excel options
    - Launch Excel manually before running the macro
    - Consider using 32-bit SAS

  If color coding is missing:
    - Verify the QUERY dataset has the expected columns:
      tblname, var, qrytype, username
    - Verify the CROSSCHK dataset has the expected columns:
      usubjid, pageid, dataset, var, line, finding
    - Check that finding codes match the supported list

  If sheets are empty:
    - Check that the library path is correct
    - Verify dataset names are NOT in the exclusion list
